# Guide des captures d'écran

Conservez uniquement des données fictives et utilisez une fenêtre de navigateur sans favoris, extensions, profil personnel ni notifications visibles.

## Captures recommandées

| Fichier | Vue | Contenu conseillé |
|---|---|---|
| `01-login.webp` | Connexion | Interface vide, email fictif |
| `02-user-dashboard.webp` | Tableau utilisateur | Réservations et salles fictives |
| `03-shared-planning.webp` | Planning partagé | Plusieurs statuts et créneaux |
| `04-new-booking.webp` | Nouvelle réservation | Formulaire complet sans donnée réelle |
| `05-admin-approval.webp` | Validation admin | Demande fictive et motif générique |
| `06-room-management.webp` | Gestion des salles | Capacités et équipements fictifs |

## Format

- largeur recommandée : 1440 px ;
- format : WebP ou PNG optimisé ;
- ratio cohérent entre toutes les images ;
- taille cible : moins de 500 Ko par capture ;
- thème et langue identiques sur toute la série.

## Contrôle avant ajout

- aucun nom de collaborateur, client ou fournisseur ;
- aucun email, téléphone, identifiant, URL interne ou adresse IP ;
- aucun logo ou document appartenant à l'organisation ;
- aucune donnée cachée dans un menu, une notification ou un autre onglet ;
- métadonnées supprimées si l'outil de capture en ajoute.
